# Cachectic Visium HD

Project utilities live in [`src`](src). Each tool/package is both:

- executable with `python -m src.<tool_or_package>`
- importable as a Python module

Each tool directory includes a minimal `README.md` and a `requirements.txt` with only the packages needed by that tool.

An aggregate Typer CLI is also available:

```bash
python -m src.cli --help
```

Main CLI commands:

```text
background                  Create background polygons or TIFF mask from H&E/RGB TIFF.
polygons                    Convert labeled TIFF masks to GeoJSON polygons.
segmentation                Run multiscale Cellpose segmentation.
segmentation-simple         Run simple single-scale Cellpose segmentation.
utils tiff-split            Split block TIFF into sample TIFFs.
utils tiff-merge            Merge sample TIFFs into block coordinates.
utils geojson-merge         Merge sample GeoJSON annotations into block coordinates.
spatial-data build          Build block and sample SpatialData zarr stores.
spatial-data merge          Merge multiple SpatialData zarr stores.
spatial-data qc             Summarize and plot a SpatialData zarr store.
```

## Input/Output Convention

Raw inputs are read only from:

```text
INPUTS/
```

All generated intermediate and final outputs are written to:

```text
OUTPUTS/
```

If a later command needs an artifact generated by an earlier command, it reads it from `OUTPUTS/`, not from `INPUTS/`.

Run commands from the repository root:

```bash
cd /Users/riccardo/Develop/cachectic_visiumHD
```

## Sample Regions

`INPUTS/configs/samples_he.geojson` is a Napari-style GeoJSON `FeatureCollection`. Each polygon feature must include:

```json
{
  "object_type": "annotation",
  "isLocked": false,
  "block": "blocco1",
  "sample": "sham",
  "name": "sham",
  "sample_key": "blocco1_sham"
}
```

The scripts use each polygon's external bounding box for TIFF splitting/merging and SpatialData crops.

## Pipeline Through The Aggregate CLI

The workflow can be run through the Typer CLI:

```bash
python -m src.cli --help
```

### 1. Merge Sample-Level ARVIS Nuclei Masks

```bash
python -m src.cli utils tiff-merge blocco1 \
  --json INPUTS/configs/samples_he.geojson \
  --images-dir INPUTS/ARVIS/arivis_blocco1 \
  --output OUTPUTS/ARVIS/Project_BLOCCO_1_ch00.tif
```

### 2. Convert ARVIS Nuclei Mask To GeoJSON Polygons

```bash
python -m src.cli polygons \
  --image-mask OUTPUTS/ARVIS/Project_BLOCCO_1_ch00.tif \
  --output OUTPUTS/ARVIS/Project_BLOCCO_1_ch00_polygons.geojson
```

### 3. Prepare Cellpose Fibre Polygons

If the block-level Cellpose mask already exists:

```bash
python -m src.cli polygons \
  --image-mask INPUTS/CellPose/Project_BLOCCO_1_ch00.tif \
  --output OUTPUTS/CellPose/Project_BLOCCO_1_ch00_polygons.geojson
```

If Cellpose needs to be run first:

```bash
python -m src.cli segmentation \
  --input-dir INPUTS/H\&E \
  --output-dir OUTPUTS/CellPose \
  --image-ext .tif \
  --scales 4,3,2,1 \
  --primary-scale 4
```

### 4. Merge ROI / In-Tissue GeoJSON Annotations

```bash
python -m src.cli utils geojson-merge blocco1 \
  --json INPUTS/configs/samples_he.geojson \
  --geojson-dir INPUTS/ARVIS/intissue_GFP_blocco1 \
  --output OUTPUTS/ARVIS/Project_BLOCCO_1_ch00.geojson
```

### 5. Create Background Polygons

```bash
python -m src.cli background \
  --image INPUTS/H\&E/Project_BLOCCO_1_ch00.tif \
  --output OUTPUTS/H\&E/Project_BLOCCO_1_background_mask.geojson
```

### 6. Build Block And Sample SpatialData Objects

```bash
python -m src.cli spatial-data build blocco1 \
  --samples-json INPUTS/configs/samples_he.geojson \
  --spaceranger INPUTS/SpaceRanger/blocco1/outs \
  --fullres-image INPUTS/H\&E/Project_BLOCCO_1_ch00.tif \
  --wga-rgb-image INPUTS/H\&E/Project_BLOCCO_1_ch00.tif \
  --nuclei-polygons OUTPUTS/ARVIS/Project_BLOCCO_1_ch00_polygons.geojson \
  --fibres-polygons OUTPUTS/CellPose/Project_BLOCCO_1_ch00_polygons.geojson \
  --background-polygons OUTPUTS/H\&E/Project_BLOCCO_1_background_mask.geojson \
  --roi-metadata OUTPUTS/ARVIS/Project_BLOCCO_1_ch00.geojson \
  --output-dir OUTPUTS/spatialdata
```


### 7. QC The Built Objects

```bash
python -m src.cli spatial-data qc \
  --zarr OUTPUTS/spatialdata/blocco1.zarr \
  --coordinate-system blocco1
```

```bash
python -m src.cli spatial-data qc \
  --zarr OUTPUTS/spatialdata/blocco1_sham.zarr \
  --coordinate-system blocco1_sham
```

### 8. Merge Sample SpatialData Objects

```bash
python -m src.cli spatial-data merge \
  --output OUTPUTS/spatialdata/blocco1_samples_merged.zarr \
  blocco1_c26STAT3=OUTPUTS/spatialdata/blocco1_c26STAT3.zarr \
  blocco1_sham=OUTPUTS/spatialdata/blocco1_sham.zarr \
  blocco1_c26foxO=OUTPUTS/spatialdata/blocco1_c26foxO.zarr
```

For multi-block analysis:

```bash
python -m src.cli spatial-data merge \
  --output OUTPUTS/spatialdata/all_samples_merged.zarr \
  blocco1_c26STAT3=OUTPUTS/spatialdata/blocco1_c26STAT3.zarr \
  blocco1_sham=OUTPUTS/spatialdata/blocco1_sham.zarr \
  blocco1_c26foxO=OUTPUTS/spatialdata/blocco1_c26foxO.zarr \
  blocco2_c26=OUTPUTS/spatialdata/blocco2_c26.zarr \
  blocco2_c26murf1=OUTPUTS/spatialdata/blocco2_c26murf1.zarr \
  blocco2_c26SMAD23=OUTPUTS/spatialdata/blocco2_c26SMAD23.zarr
```
